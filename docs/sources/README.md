# Source index

Every outside source the project has read or looked up, so it can be found again. One row per source. **The details of what a source said stay in the decision entry named in the last column** (not copied here); this index says what the source is, how it was got, whether it was read, what rights it carries and what it was used for.

**Rules.** Add a row when a source is read or looked up (same session). *Status:* `read` (the page or file was read in the session), `read, second hand` (a copy or a summary of it was read), `searched` (only a search result or its summary was seen: **not a source for a number until it is read**), `preview` (a publisher's sample only), `sent` (the human sent the file). *Rights:* the files of copyrighted standards, articles and catalogues are **not** kept in the repository; the human keeps the files sent (file name as received is given); the formulas used are facts and are written in the code with the source named. Links go stale: the date read is given. A source that disagrees with another is marked in its decision entry, not here.

- From the search summaries: typical draft in sand casting about 1° to 2°, 1.5° manual green sand and 2° for deep pockets, 1° automated, shallow walls needing more draft than deep ones (SFSA supplement; Batesville permanent mold aluminum design guide https://batesvilleproducts.com/wp-content/uploads/2024/01/Design-Guide-for-permanent-mold-aluminum-casting.pdf). Wall minima: about 0.10 in (aluminum), 0.13 in (magnesium, steel), 0.18 in recommended for gravity permanent mold aluminum (https://www.engineersedge.com/sand_cast.htm, the Batesville guide). Fillet at a junction: the blending radius equals the wall thickness for equal walls, the average of the two for unequal ones (Batesville). Sharp internal corners are the common mistake (engineeringproductdesign.com). Machining allowance grows with the casting's greatest dimension (ISO 8062; table not seen).
- Machining (https://www.emachineshop.com/cnc-inside-corner-radius/, https://www.3dhubs.com/knowledge-base/sharp-corners-in-cnc-machining/, https://onshape.com/en/blog/cnc-machining-101-endmills-other-considerations): an inside corner cannot be sharper than the tool's radius; make the radius bigger than the tool's (larger is cheaper); a floor radius smaller than the wall radius lets one tool cut both; a rule of thumb for a fillet at the foot of a wall: more than 1/3 of the wall's height.
