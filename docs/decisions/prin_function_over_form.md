# Function over form

Build a robust engine first; polish comes after correctness. A clean, stable, fast tool beats a
beautiful broken one.

## Rationale
Human-authored: blueprint section 5, principle 3. Stability is the main complaint about the tool the
target user leaves (FreeCAD).
